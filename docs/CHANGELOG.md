# 更新记录

## 0.2.1 · 2026-11-07

- 修复 Blockly 分类栏层级高于启动弹窗遮罩的问题；画布独立层叠，页面级 Blockly 编辑器和提示也放到应用弹窗下方。
- 电池识别优先读 HR33；其值为零且输出关闭时，使用新读取的 HR10 端电压，并检查同次响应的 HR18。三次采样及确认后复核使用同一来源，确认弹窗和日志显示来源。
- Linux 启动器使用图标绝对路径；pacman 安装及升级后强制更新 hicolor 图标缓存。
- Windows NSIS 和 Linux pacman 包已构建；修复后的行为交由用户人工验收，未运行新测试。

## 0.2.0 · 2026-11-07

- 新增基于 Blockly / Zelos 的 Scratch 风格吸附画布，63 种积木、11 个分类；支持数值 / 条件插槽、C 形嵌套、缩放、平移、撤销和执行高亮。
- 支持数学、逻辑、文字、变量、列表统计、独立计时器、循环、断言、自定义积木及最多 16 台设备的并行控制；纯计算程序无需设备。
- 在主进程校验并解释程序，跟踪设备占用、过期数据、异常和取消，结束后关闭绑定输出并回读确认；程序库支持保存、导入、导出及会话草稿。
- 内置 4.2 V / 串锂电池充电、电压阶梯扫描、双设备电压跟随示例。充电限流每次填写，串数估算后确认，恒压末期电流低于 0.1 A 连续超过 10 s 后结束。
- 提供自动构建 Core 的 Windows x64 NSIS / Linux x86_64 pacman 打包命令、品牌安装向导、统一应用图标和 SHA-256 校验文件。
- 开发阶段 27 项测试和前端构建通过；PTY 使用模拟设备，未进行真实电池充电和 Windows 原生串口验收。
